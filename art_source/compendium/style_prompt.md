# Compendium style-reference prompt

Generated with the built-in image generation tool as a visual direction source. The native-size
game textures are authored and reproducibly exported by `tools/CompendiumTextureExporter.java`.

```text
Use case: stylized-concept
Asset type: Minecraft hardcore-survival mod texture style reference sheet for a compendium item and GUI
Primary request: Create a cohesive pixel-art style sheet for a rough handmade survival compendium. Show, as clearly separated visual samples: a worn self-bound notebook made from bark/rag paper tied with plant cord; a dark open double-page spread with fibrous paper and a plant-cord center binding; a shallow inset inventory slot; normal and hovered page panels; recessed and selected paper/leather side tabs; a charcoal-outlined recipe card; a hand-drawn 3x3 knowledge grid; five uneven handwritten lines; a small crooked ink checkmark; and a nearly empty water droplet status icon.
Style/medium: crisp low-resolution Minecraft-compatible pixel art, hard pixel edges, no anti-aliasing, no smooth gradients, readable tiny silhouettes
Composition/framing: organized sprite-sheet presentation with generous spacing between every sample, each sample isolated and fully visible
Lighting/mood: dim underground survival, handmade, practical, worn
Color palette: warm very dark brown-gray paper around #1E1A17, inset slot around #4E4E4E, muted gray-beige fibers, charcoal ink, dull plant-fiber tan, muted blue-gray #3A6B7C only for the water droplet
Materials/textures: smoke-darkened bark paper, rag fibers, frayed edges, plant cord and knot, rough charcoal strokes
Constraints: no readable text; no gold; no blue except the droplet; no glow; no fantasy ornament; no leather book cover; all UI surfaces opaque; slot interior distinctly lighter than the page; preserve strong pixel-art readability
Avoid: modern UI, clean straight vector edges, ornate medieval manuscript decoration, saturated colors, shadows outside isolated item/icon samples, watermark
```

## Open-book redesign prompt

It asked for two physically separate rag-paper pages, an uncovered center gutter, a worn cover,
non-vanilla paper controls, side category bookmarks, and six top bookmarks with distinct pictograms
for crafting, loot, cooking, smithing, smelting, and in-world work. The generated reference is saved
as `open_book_redesign_reference.png`; the exact native-size implementation remains generated by the
