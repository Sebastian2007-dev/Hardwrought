# Drawn texture sources

These source images were created with the built-in image generation tool. Export the
native Minecraft PNGs with `python tools/export_requirement_icons.py` (Pillow required).
Each image source is kept beside the other artwork in `art_source/`.

Shared prompt constraints: one centered object on a square canvas; Minecraft inventory
pixel art with a strict square grid, crisp hard edges, readable at 16x16, restrained
earthy industrial colors, transparent background, and no text, border, shadow, scene,
extra objects, gradient, or antialiasing.
